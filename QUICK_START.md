# ⚡ Quick Start Guide

Get your advanced GitHub profile up and running in 10 minutes!

## 🚀 5-Step Setup (Essential)

### Step 1: Check Repository (30 seconds)
✅ Repository name matches your username: `kamalprajapat21`  
✅ Repository is **PUBLIC**  
✅ README.md exists  

### Step 2: Enable GitHub Actions (1 minute)
1. Go to **Settings** → **Actions** → **General**
2. Under "Workflow permissions":
   - Select **"Read and write permissions"**
   - Check **"Allow GitHub Actions to create and approve pull requests"**
3. Click **Save**

### Step 3: Create Output Branch (2 minutes)
Open terminal in your repository folder and run:

```bash
cd kamalprajapat21
git checkout --orphan output
git rm -rf .
echo "# Snake Animation Output" > README.md
git add README.md
git commit -m "Initialize output branch"
git push origin output
git checkout main
```

### Step 4: Update Personal Info (5 minutes)
Replace in **README.md**:
- [ ] Your name (if different)
- [ ] Email: `kamalprajapat7117@gmail.com`
- [ ] LinkedIn URL
- [ ] Portfolio URL
- [ ] Twitter/other social URLs
- [ ] Current role/company
- [ ] Location

### Step 5: Trigger Workflows (1 minute)
1. Go to **Actions** tab
2. Select "Generate Snake Animation"
3. Click **"Run workflow"** → Run
4. Select "Update Recent Activity"  
5. Click **"Run workflow"** → Run

✅ **Done!** Your advanced profile is live!

### Snake Not Showing?

### Stats Not Loading?

- Wait 5 minutes and refresh
- Try incognito mode

- Normal for first 30 minutes
