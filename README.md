## 🚀 Featured Work

<details open>
<summary><b>🏥 Dooper Health — Production Healthcare Platform</b></summary>
<br/>

Primary developer across five live products: patient portal PWA, lab management system, doctor platform, admin panel, and pharmacy app.

- Built and operate the full stack: React + Node/Express + MongoDB Atlas, deployed on AWS EC2 with Docker
- Set up CI/CD with GitHub Actions and manage the deployment pipeline end-to-end
- Integrated WhatsApp Cloud API notifications for patients/doctors using BullMQ job queues
- Implemented Razorpay payment webhooks and PWA push notifications
- Debugged production incidents: Redis and PM2 crash loops, EC2/Docker deployment issues
- Set up ZeptoMail for transactional email while awaiting AWS SES approval
- Configured domain security and SEO schema markup for the platform
